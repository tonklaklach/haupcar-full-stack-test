# HAUP Car Registry

## รันบนเครื่อง

เปิดเทอร์มินัลแรกที่โฟลเดอร์โปรเจกต์แล้วรัน

```sh
cd backend
go run ./cmd/api
```

เปิดอีกเทอร์มินัลที่โฟลเดอร์โปรเจกต์แล้วรัน

```sh
cd frontend
npm ci
npm run dev
```

## REST API

| Method | Path | สำเร็จ |
| --- | --- | --- |
| GET | `/health` | `200` |
| GET | `/api/cars` | `200` พร้อมรายการทั้งหมด |
| GET | `/api/cars/:id` | `200` พร้อมข้อมูลรถ |
| POST | `/api/cars` | `201` พร้อมข้อมูลและ `Location` |
| PUT | `/api/cars/:id` | `200` พร้อมข้อมูลหลังแก้ไข |
| DELETE | `/api/cars/:id` | `204` |

```sh
curl -i http://127.0.0.1:8080/api/cars \
  -H 'Content-Type: application/json' \
  -d '{"registration":"1กข-2345","brand":"Toyota","model":"Yaris","notes":"รถสำรอง"}'
```

ทะเบียนรถรับอักษรไทย 2 ตัว อาจมีเลขนำหน้า 1 หลัก และมีเลขท้าย 1–4 หลัก ระบบเก็บในรูปแบบ `4ขห-798` หรือ `ขก-1234` แม้ส่งมาโดยเว้นวรรคหรือไม่ใส่ขีด

POST และ PUT รับข้อมูลรูปแบบเดียวกัน โดย PUT แทนที่ข้อมูลที่ผู้ใช้แก้ไขได้ทั้งหมด API ตอบ `400` เมื่อข้อมูลไม่ถูกต้อง, `404` เมื่อไม่พบรถ และ `409` เมื่อทะเบียนซ้ำ
